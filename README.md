# Indie Agent Ship Kit — Free Teaser

A practical sample from **Indie Agent Ship Kit** (`indieagentkit`): agent skills, SOPs, and templates for solo founders who ship digital products with Cursor or Claude Code.

No fluff. No hype slogans. Just files you attach to your agent and run.

## Who this is for

- Solo founders and indie hackers building small paid products (Notion packs, templates, scripts, checklists, micro-tools)
- People already using Cursor Agent, Claude Code, or similar coding agents
- Anyone who wants a repeatable path from idea → listing → first buyers without a team

## What's in this free teaser

| Path | What it is |
|------|------------|
| `skills/product-ideation.md` | Full skill: go from scattered ideas to one offer you can ship in 7 days |
| `sops/anonymous-brand-hygiene.md` | Short SOP: keep personal identity out of public product assets when you want an anonymous brand |
| `LICENSE` | MIT (this teaser only) |

### How to use a skill

1. Open `skills/product-ideation.md`
2. Attach it (or paste it) into Cursor / Claude Code
3. Add one paragraph of product context
4. Ask the agent to run the skill step by step and stop for your approval before sales copy

Example prompt:

```
Use the attached skill. Context: I'm shipping a $29 PDF checklist pack
for freelancers who invoice late. Audience is US freelancers on Twitter/X
and Indie Hackers. Run steps 1–4 and stop for my approval before writing
the listing description.
```
